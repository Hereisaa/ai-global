# 代理治理使用手冊

> 外部參考路徑：本檔的 `../` 連結以 ai-global clone 的 `governance/` 為基準；部署副本請先從 `~/.ai-global/.deploy-state.json` 取得 `source_repo` 再解析。只在任務需要時讀取，不遞迴載入。

本手冊給使用者閱讀。治理檔保存專案知識與工作約定；工具權限與自動檢查負責可強制的限制。模型更新後仍需檢查兩者，但不必保留每一條歷史流程。

## 四種狀態要分開

| 狀態 | 意義 | 怎麼確認 |
|---|---|---|
| 掛載 | 檔案或連結位於工具預期位置 | 檢查路徑、連結目標與內容 |
| 讀取 | 當前工作階段真的載入相關規則 | 查看工具的載入資訊或日誌，抽查檔案來源 |
| 遵循 | 這次行動符合規則 | 對照實際行動、產出與驗證證據 |
| 強制 | 即使模型選錯，執行環境仍會拒絕 | 用允許及拒絕案例測試權限、sandbox、hooks 或 CI 保護 |

掛載不等於讀取，讀取不等於遵循，遵循一次也不等於環境已強制。router 中的一個路徑只是路由，不保證被引用全文自動載入。工具差異見 [執行環境參考](../docs/reference/agent-runtime.md)。

## 日常使用

- 提供要解決的問題、範圍與可接受成果。只要分析時明說「先評估」；要實作時直接授權範圍。
- 「你來改良」等明確實作授權，允許範圍內可逆修改繼續進行；不必再批准每一個一般實作細節。何時需要確認與何時完成，統一依 [20-judgment.md](20-judgment.md)。
- 改制度走 [40-maintenance.md](40-maintenance.md)；安全規範查 [50-safety.md](50-safety.md)。治理變更需要獨立審查，其他工作依風險安排驗證。
- 驗收時要求「結論、實際證據、未驗證範圍」。不要把代理自述已讀或已完成視為唯一證據。
- 要保留教訓時明確指定寫到哪裡；一般收尾不自動修改記憶或制度。

## 檢查倉庫與本機

在 ai-global 倉庫執行：

```bash
python3 setup/govcheck.py --local
```

`--local` 已包含倉庫靜態檢查；只需離線檢查時省略參數，不重跑兩者。檢查範圍以腳本輸出為準，通過不代表模型遵循、hooks 被觸發或安全邊界已完整驗證。部署與同步入口見 [倉庫 README](../README.md)。

| 類別 | 應報告的證據 | 本手冊未聲稱已完成的部分 |
|---|---|---|
| 安全 | 當前 sandbox、網路、權限配置及拒絕案例 | 本機全面隔離或所有工具均被同一規則涵蓋 |
| 授權 | 本次使用者授權範圍與實際待執行動作 | 尚未授權的發布、寄送、push 或不可逆操作 |
| 已驗證 | 本次實跑的指令、結果、檔案與日期 | 不能沿用歷史快照冒充現況 |
| 未驗證 | 尚未檢查的平台、runtime、hook 觸發、CI 或遠端保護 | 不以檔案存在或設定文字取代實測 |

本次文件更新不代表已修改本機 settings、啟用 Stop hook、更新模型、執行遠端 CI 或同步另一台機器；這些都須各自取得證據。舊狀態表已保留於歷史備份，不作當前承諾。

## 值得重新檢查的訊號

規則彼此衝突、路由不存在、反覆要求同一授權、宣稱完成卻沒有證據，或文件越來越長時，提出針對性的制度修正。先找具體失敗與責任檔，不把所有細節加進全域入口。模型名稱或能力宣傳不能證明治理已生效。
