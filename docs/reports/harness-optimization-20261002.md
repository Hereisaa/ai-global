# ai-global 全面優化交付紀錄

2026-10-02。使用者在工程師日常開發與 agentic workflow 的功能評估後，授權全面優化。基準為 `7aad699`，工作分支 `codex/harness-eval`。本輪是本機修改與部署，不包含遠端 push。

## 完成的行為調整

| 原本 | 現在 | 用意 |
|---|---|---|
| align 補裝所有 manifest 缺項 | 只自動補裝基本；選配需明確 --only | 避免每台機器都裝研究、設計與維護能力 |
| 本機能力開關與 manifest 不同就算衝突 | 保留本機選擇；明確停用的 plugin 不要求更新版本 | 同步不反覆打擾已做過的選擇 |
| 能力混在同一清單 | 新增用途分組與 --group 篩選，TUI 刷新保留篩選 | 更容易找到這次任務需要的能力 |
| 入口標題不同就失敗 | 改為提醒；失效路由與錯誤工具前綴仍失敗 | 把檢查重點放在實際規則與連結 |
| 外部來源日期過舊就警告、evolve 預設全查 | 日期只列資訊；升級或異常時查相關來源 | 避免為了日期而做無效維護 |
| 所有專案複雜動畫都指定 GSAP | 先沿用專案選擇；GSAP 建議移入選配指南 | 後端與其他專案不必承擔特定前端偏好 |
| eval 只有完整首輪設計 | 增加依變更範圍選題的規則 | 小改跑小檢查，安全或載入改版再跑相關模型任務 |
| align 文件把未回覆當預設決定 | 未回覆保留待決，與腳本行為一致 | 沒有回覆不等於同意覆蓋或移除 |

另修正 Codex 版本衝突說明誤讀 Claude registry 的問題，避免 Codex 獨有 plugin 發生 KeyError。

## 本機配置

本機已確認安裝且啟用的 12 項選配停用但不卸載；保留 core 與既有 TypeScript 支援。frontend、research、maintenance 可用 capabilities.py 逐項再開；未納管能力與工具內建插件保留。設定修改先備份到 `~/.ai-trash/ai-global-settings-<唯一值>/`，前後語義比對確認其他設定欄位不更動。當次對話可能仍載入舊能力，需新對話確認。
